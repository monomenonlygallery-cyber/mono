# Как редактировать тексты на сайте monó

## Где находятся все тексты

Все тексты сайта (заголовки, описания, цены, вопросы FAQ, тексты кнопок,
адрес, ссылка на Instagram) вынесены в один файл:

**`content.js`**

Открой его — там понятные названия полей, сгруппированные по разделам сайта
(`hero`, `prices`, `faq`, `contact` и т.д.), с комментариями на русском,
которые объясняют, что где находится.

## Какой файл отдавать Claude для текстовых правок

Всегда **только `content.js`**. Больше ничего прикреплять не нужно.

## Какие файлы нельзя менять при обычной замене текста

- `index.html` — вся вёрстка, дизайн, SEO, Schema.org, подключение шрифтов
- `content-loader.js` — техническая логика, которая подставляет текст из
  content.js на страницу
- вся папка `images/` — фотографии

Если Claude предлагает менять что-то из этого списка ради простой правки
текста — это сигнал, что просьба сформулирована не туда или требует другого
подхода (см. ниже раздел "Что нельзя поменять просто текстом").

## Как обновить сайт через GitHub после изменения

1. Скачай новый `content.js`, который прислал Claude
2. Зайди в свой репозиторий на GitHub
3. Открой файл `content.js`, нажми на иконку карандаша (Edit)
4. Вставь новое содержимое, нажми "Commit changes"
5. Через 1–2 минуты GitHub Pages обновит сайт автоматически

Ничего больше делать не нужно — не нужно ничего пересобирать или загружать
заново весь проект, если менялся только текст.

## Какие изменения безопасны (делаются только через content.js)

- Любые заголовки и подзаголовки
- Любые цены (по зонам, пакетам, комбо)
- Тексты кнопок (CTA)
- Вопросы и ответы FAQ
- Тексты отзывов и имена авторов
- Адрес (улица, город) и подпись Instagram-ссылки
- Тексты в блоке "как это работает", "кому подходит", "сравнение" и т.д.

## Что нельзя поменять просто текстом (нужна отдельная работа)

- **Номер телефона и текст WhatsApp-сообщения.** Они "зашиты" в рабочих
  ссылках (`tel:` и `wa.me`) сразу в нескольких местах `index.html`. Если их
  вынести в content.js без доработки кода, есть риск, что видимый текст и
  реальная ссылка разойдутся — кнопка будет показывать один номер, а писать
  на другой. Это тот риск, который в задании было явно нельзя допускать.
  Если номер/сообщение поменяются — попроси Claude сделать точечную правку
  ссылок в HTML, это отдельная, более аккуратная задача.
- **Заголовок блока "Achseln Bikini Beine Oberlippe Intim Arme"** (тёмный
  блок "что мы умеем лучше всего") — там текст разбит на кусочки с разным
  оформлением (обычный / жирный шрифт) прямо в HTML-коде, вынести его в
  content.js как простой текст было бы небезопасно для вёрстки.
- Порядок и количество секций, дизайн, цвета, фотографии, время загрузки
- Часы работы студии — сейчас на сайте нет фактических часов работы (плейсхолдер
  в Schema.org), их нужно один раз добавить вместе с Claude напрямую в HTML

## Как формулировать запрос Claude

Скопируй и заполни:

> Внеси только следующие текстовые изменения в content.js. Не изменяй HTML,
> CSS, структуру сайта, изображения, SEO и функциональность. После правки
> покажи список изменённых полей.
>
> 1. [поле] → [новое значение]
> 2. [поле] → [новое значение]

Пример:

> Внеси только следующие текстовые изменения в content.js. Не изменяй HTML,
> CSS, структуру сайта, изображения, SEO и функциональность. После правки
> покажи список изменённых полей.
>
> 1. prices.zones.fullLegs.price1 → 149 €
> 2. faq.items.q3.answer → новый текст ответа
